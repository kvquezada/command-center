# Build a task

A task builds only when its source is approved ("Approved by" filled in on the spec or diagnosis) and it has no open question of its own.

- **In the session:** **incremental-implementation** with **tdd**: implement a slice, test it, verify it, commit it, then the next slice.
- **Through the factory:** write the task's run brief and run `sdlc` with it. One brief is one run and one PR.

Which path a task takes, and the run brief's format, are being settled on the map ("Build here or hand to sdlc", "Plan and run brief format"). Until then, build in the session.
